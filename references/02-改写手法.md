# 02 · 改写手法（删 / 换 / 补 / 转 / 接）

> 五法对应五类病。**先定病，再选法**——用错法会把句子改坏。
> 每法都有一条**禁止线**，越线就是"改坏"。
>
> 例句出自虚构示例剧本《末班车》，`examples/demo_rewrite_map.json` 是这 9 条的完整映射，可直接复现。

---

## 删 · 治「水词 / 复述 / 端着的总结」

**操作**：整句删不了就删半句；保留信息，只删不承载信息的字。

### 案例 1 · 砍掉端着的总结句

```
原：我以为他会点头。他没抬头。往后的路，得自己一步一步踩出来。
```
**诊断**：前两句好（有信息、有画面：他点头/抬头两个动作就是态度）。第三句"往后的路，得自己一步一步踩出来"是**端着的总结句**——文笔 3 级，空，且把情绪解释完了。

```
改：我以为他会点头。他没抬头。
```
**依据**：删掉解释，留白更狠。观众自己会得出"只能靠自己"的结论——你替他说出来，反而弱了。

> **规律**：凡是"往后的路…""这一切…""命运…""从今以后…"开头的收尾句，九成可删。

### 案例 2 · 纯应答升级

```
原：阿亮：哦。
```
**诊断**：纯应答，零信息零推动。

```
改：阿亮：哦。那我再数一遍。
```
**依据**：把"知道了"换成**一个具体行动**（他要复核），信息（重新数）和推动（他动起来了）同时有了。

### ❌ 禁止线
**不许把水词删成空行**。删完必须是"信息更集中"，不是"少了半句"。行数不能变（硬约束 2）。

## 换 · 治「书面腔 / 译制片腔 / 长句」

**操作**：书面词 → 口语词；完整句 → 半截句；被动 → 主动；长句 → 断成两句。

### 案例 3 · 书面词替换

```
原：周小满：站长，我要求核查上午的售票记录。
```
**诊断**：`要求` `核查` 都是公文词，售票员不会这么说。

```
改：周小满：站长，把上午的售票记录给我看。
```
**依据**：`要求核查`→`给我看`，长句断成两截。**逼人的劲反而更足**——"要求"是下级对上级的申请，"给我看"是平级的对峙。

### 案例 4 · 讲道理 → 下结论

```
原：周小满：但我不能让她觉得，这钱认了就完了。
```
**诊断**：`不能让她觉得…就完了` 是**作者在讲道理**，不是角色在说话。这句读起来通顺（2 级），但不像人话。

```
改：周小满：这四块二，得有人签个字。
```
**依据**：把"讲道理"压成一个**判断 + 一个动作指向**。`四块二`/`签字` 都是具体词。

### ❌ 禁止线
**不许为了"口语化"拉低身份**。书生引典、干部说官话、老技工惜字——都是人设，不能改。判准：这段"不口语"是**剧情需要**还是**作者没写**？前者不动。

## 补 · 治「流水账（文笔 4 级）」

**操作**：补**一个**可感锚点——动作方式 / 物件 / 数字 / 声音 / 停顿。**只补一个**。

### 案例 5 · 补地点

```
原：阿亮：我去拿抹布。
```
**诊断**：信息清楚，但脑子里没有画面（4 级）。

```
改：阿亮：抹布在门后钉子上，我去拿。
```
**依据**：`门后钉子上` 一个方位锚点，把"他去拿"变成了可看的空间——观众立刻知道这屋子长什么样。

### 案例 6 · 已经是 1 级，不动

```
原文：周小满：四十一张。收的钱，十七块八。
```
**诊断**：这句已经是 1 级——数字本身就是画面，两个数字一撞，缺口自己出来了。**不动**。

> **反例警示**：不要给这种句子再补细节。补了就是画蛇添足。

### ❌ 禁止线
**只补一个，不许补三个**。补三个就从 4 级跳到 3 级（堆砌）。
```
❌ 阿亮：抹布在门后钉子上的那个塑料筐里，我上午刚洗过，还湿着。
（三个细节并列 = 堆砌，读着累）
```

## 转 · 治「情绪直白 / 说明式交代」

**操作**：把"说出来的情绪/背景"转成**可见行为**或**潜台词**。三种招式：

### 招式 A · 借物说话

```
原：周小满：我不能留你。
改：周小满：水开了。喝完这碗再走。
```
字面是留客，行动是赶人，风险是话不能说破（还要在一个站里过）。

### 招式 B · 答非所问

```
原：王秀兰：你就不怕他把责任都推你身上。
    周小满：我不怕。
改：王秀兰：你就不怕他把责任都推你身上。
    周小满：记录上就三十九张。
```
**依据**：不正面回答，用**事实本身**当答案。观众自己算出"他心里有鬼"——比说"我不怕"高一档。

### 招式 C · 掉尾（说一半）

```
原：周小满：你要是敢动她，我绝对不会放过你。
改：周小满：你要是敢动她——
```
**依据**：威胁的后半句由对方脑补，永远比你写出来的狠。**用法**：威胁、诀别、说不出口的告白。**一集最多一次**，多了变结巴。

### 案例 7 · 说明式交代 → 只留物证与缺口

```
原：阿亮os：这一摊子事跟乱麻似的，我心里说不清是什么滋味。
```
**诊断**：这是纯情绪介绍（P2 堆词）。`跟乱麻似的` 是**比喻**，`说不清是什么滋味` 是**替观众下结论**，两样都不是画面。

```
改：阿亮os：票根上的数，对不上。
```
**依据**：砍掉所有修辞，只留**一个具体物证**（票根上的数）+ **一个事实判断**（对不上）。缺口比抒情有用——它让观众想看下去。

### ❌ 禁止线
**不许把直白改成谜语**。潜台词要有**推断线索**（物件、称呼、答非所问、与眼前景象矛盾）。没有线索的"话里有话"＝装深沉，观众看不懂（掉到 5 级）。

## 接 · 治「各说各话」

**操作**：让这句**接住上一句**——顶回去、反用对方的词、或把选择权丢回去。

### 案例 8 · 顶回去

```
原：马德胜：站里要查，你也不一定清白。
    阿亮：我哪知道啊。
```
**诊断**："我哪知道"是接了，但只是被动反应，且零信息。

```
改：阿亮：我上午在擦车。
```
**依据**：把被动辩解升级成**提供事实**——顺手把自己摘出去，还给了周小满一条新线索（十点他在擦车，那谁在窗口）。

### 案例 9 · 反用对方的词（高阶）

```
原：赵科长：你这话，是在说谁？
    周小满：我说的是账。您问的是人。
改：不动。
```
**诊断**：这是**范本级**的接法——把对方抛来的词原样退回，指出他答错了题。文笔 1 级，1 级的标准就是这种"读完脑子里直接看见"。

> **任务不是把所有对话都改成这样，而是认出这种句子并保护它。**

### ❌ 禁止线
**不许改变谁占上风**。改写只调整"怎么说"，不动"谁赢谁输"。原文周小满压住马德胜，改完还得压住。

## 五法速查

| 病 | 法 | 一句话 |
|---|---|---|
| 水词 / 复述 / 总结句 | **删** | 删到只剩信息 |
| 书面腔 / 长句 / 讲道理 | **换** | 换成具体词、半截话 |
| 流水账（4 级） | **补** | 补一个可感锚点，只一个 |
| 情绪直白 / 说明式 | **转** | 借物 / 答非所问 / 掉尾 |
| 各说各话 | **接** | 顶回去 / 反用词 / 丢回去 |

## 改完必过的四问（逐句）

1. 删掉这句，剧情会不会断？——不断且不爽感不掉 → 废句
2. 这句能不能被对方听见？——听不见＝自言自语，改
3. 这句有没有接住上一句？——没有＝各说各话，改
4. 遮住角色名，认得出是谁在说吗？——认不出＝没立住，改

## 改动力度纪律

**P3（不动）通常占多数。** 一次全量改写，命中率控制在 **20–35%** 是健康的。
超过 50% 说明你在为了产出而制造改动——那会把已经达 1 级的句子改坏。

> 示例剧本只有 47 条台词，改 9 条即 19.1%，落在下沿——因为这份稿子本来就不差。**改得少不丢人，改坏了才丢人。**
