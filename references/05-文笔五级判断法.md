# 05 · 文笔五级判断法

> 这份文件的唯一目的：让你（和改写的人）**一眼判出这句是几级**，然后知道**往哪个方向修**。
> 五级不是一条直线，是**一个正峰两个反坡**——3 级和 4 级是两种相反的错。

---

## 一、核心公式

`雨砸在青石板上` 这个例子值得拆开看，它一个形容词都没有：

```
雨  （具体名词）
砸  （强动词 —— 不是"落下"，是"砸"）
青石板（具体名词，有质地、有颜色）
```

**1 级 = 强动词 + 具体名词**。就这么简单。
它不靠修辞，靠**动词选得准**和**名词选得实**。

反过来看 3 级：

```
晶莹的泪珠 如断线的珍珠般 滚落
↑形容词      ↑比喻           ↑弱动词
```

三个装饰，零个具体信息。**这就是"穿了一身名牌却没说人话"。**

## 二、同一件事的五个版本（判定标尺）

### 例 A · 叙事句："她哭了"

| 级 | 句子 | 判定依据 |
|---|---|---|
| **1** | `眼泪砸在手背上。` | 强动词"砸" + 具体名词"手背"，读完脑子里有画面 |
| **2** | `她低下头，眼泪掉下来。` | 逻辑通顺、有动作顺序，但"掉"是中性动词，画面一般 |
| **3** | `晶莹的泪珠如断线的珍珠般滚落。` | 形容词"晶莹" + 比喻"如断线的珍珠" + 弱动词"滚落"，抽掉修饰什么都不剩 |
| **4** | `她哭了。` | 只有事件，没有方式、没有画面，流水账 |
| **5** | `她的情绪一下子涌了上来，那些说不清道不明的东西顶在喉咙口，她也不知道自己到底是在为谁难过。` | 三个"说不清"，指代不明，读者读完不知道发生了什么 |

### 例 B · 台词句："这四块二不是我拿的"（出自示例剧本《末班车》）

| 级 | 台词 | 判定依据 |
|---|---|---|
| **1** | `周小满：我垫。账留着。` | 6 个字，两个动作，一个字都不多。**认账，但不认罪**——身份、态度、后手全在里面 |
| **2** | `周小满：这四块二我先垫上，账你别划掉。` | 通顺、信息完整，但把 1 级那句的狠劲解释掉了 |
| **3** | `周小满：关于这笔款项，我自有一份清白可以自证。` | 书面堆砌，1995 年县城售票员不会这么说 |
| **4** | `周小满：这钱不是我拿的。` | 只有否定，没有动作、没有筹码，人物完全消失 |
| **5** | `周小满：这钱的事你要这么算，那我说的就不是那个意思了，反正你心里明白。` | 指代不明、逻辑绕圈，观众读两遍不知道她在说啥 |

> **注意**：例 B 的 2 级和 1 级差别不在"通不通顺"，而在**有没有那个让人看见的东西**。"我垫"是动作，"我先垫上"是叙述。通顺是 2 级的门槛，不是 1 级的标准。

## 三、五级判定速查（30 秒判一句）

按顺序问，命中即停：

```
Q1 读完这句，我脑子里有没有出现具体的画面/动作/物件？
   → 有，且没有多余修饰 → 【1 级】停
   → 有，但靠形容词堆出来的 → 【3 级】

Q2 句子通顺吗？前因后果清楚吗？指代明确吗？
   → 不通 / 指代不明 / 一句话三个意思 → 【5 级】停
   → 通顺 → 继续

Q3 形容词 + 成语 ≥ 3 个，或出现"岁月/宿命/情愫/灵魂/救赎"类大词？
   → 是 → 【3 级】

Q4 除了"谁做了什么"，还有任何可感细节（方式/物件/数字/声音/停顿）吗？
   → 没有 → 【4 级】
   → 有 → 【2 级】停
```

**最容易混的两对**：
- **1 级 vs 3 级**：都"有画面"。区别是 1 级靠**动词和名词**，3 级靠**形容词和比喻**。
- **2 级 vs 4 级**：都"没毛病"。区别是 2 级有**细节**，4 级只有**事件**。

## 四、往哪个方向修（关键：别修反）

| 当前级别 | 病症方向 | 修法 | 禁止 |
|---|---|---|---|
| **5 级** | 逻辑崩 | **重写**：先确定"这句话要让人知道什么"，一件事只说一件事 | 不要在混乱的句子上加修饰 |
| **4 级** | 太干 | **补**一个可感锚点（动作方式/物件/数字/声音）——**只补一个** | 补三个就跳到 3 级 |
| **3 级** | 太花 | **删**：删掉所有形容词和比喻，留下最强的动词 + 最实的名词 | 不要换更漂亮的词 |
| **2 级** | 通顺但平 | **换**动词：把"中性动词"换成"带力量/方向的动词"（落→砸、走→蹭、看→盯） | 不要加比喻 |
| **1 级** | — | **不动** | **任何改动都是破坏** |

### 4 级 → 1 级的标准路径（三步）

```
4 级：周小满：我去把票根收起来。
  ↓ ① 找出这件事里最具体的一个物件
  票根 / 抽屉 / 玻璃板
  ↓ ② 给这个物件配一个强动词
  码 / 压 / 锁
  ↓ ③ 组合，控制在 15 字内
1 级：周小满：票根我按日期码好了，压在玻璃底下。
```

### 3 级 → 1 级的标准路径（两步）

```
3 级：阿亮os：这一摊子事跟乱麻似的，我心里说不清是什么滋味。
  ↓ ① 全删修辞，只问"到底发生了什么"
  票根上的数不对
  ↓ ② 换强动词 + 具体落点
  对不上
1 级：阿亮os：票根上的数，对不上。
```

## 五、分级不是目的，密度才是

**一份稿子的健康分布**（台词部分）：

| 级别 | 合理占比 | 说明 |
|---|---|---|
| 1 级 | 15–30% | 高光句。**不可能全篇都是 1 级**——全篇 1 级等于没有重音 |
| 2 级 | 50–65% | 主体。通顺、有细节、不出错 |
| 3 级 | ≤5% | 堆词，越少越好 |
| 4 级 | ≤20% | 流水账，功能性过场台词可以容忍 |
| 5 级 | 0% | 出现即改 |

**关键判断**：不要追求"每句都是 1 级"。
如果一份稿子 80% 的句子都是 1 级，那不是文笔好，那是**每句都在使劲**——读者会累。
1 级要用在**该重的地方**：情绪转折、关系变化、关键决定。

## 六、台词特有的两条附加标准

文笔五级管"文字质量"，但台词还有两个额外要求（来自你的标准）：

### 6.1 推动剧情（无效台词判定）

**删除测试**：把这句删掉，看四项有没有变化——

| 项 | 变化举例 |
|---|---|
| 信息 | 观众少知道一件事 |
| 立场 | 有人改变了态度 |
| 筹码 | 力量对比变了 |
| 关系 | 两人距离变了 |
| 行动 | 有人要去做事 |

**五项全不变 → 无效台词**。注意：**文笔 1 级也可能是无效台词**——
`周小满：窗台上都是灰。` 写得很好（1 级），但如果它不推动任何东西，还是废句。
反过来，`马德胜：四块二。补上。` 文笔只是 2 级，但它交代了数目和处置，**有效**。

### 6.2 口语化（不是"变啰嗦"）

三个硬指标：
1. **零书面虚词**（是否/因此/从而/以及/由于/进行）
2. **有口语颗粒**：语气词、垫词、半截话——但**按角色分配**，陈守义一个不加，阿亮可以多（示例里他的语气词率是 50%）
3. **长短交错**：全篇都是 4–8 字 = 电报体，也是毛病

**判准**：把台词念出来。念着别扭 → 不像人话；念着顺但记不住 → 4 级。

---

## 七、一句话总结

> **1 级靠动词，2 级靠细节，3 级错在加太多，4 级错在加太少，5 级错在没想清楚。**
>
> 改稿的方向永远只有一个：**把 3 级和 4 级往中间收，把 2 级往上抬一点，把 1 级保护好。**
