# 04 · 校验规则

> **诚实边界**：机检只能抓"低级错误"，抓不出"台词好不好"。
> **机检 FAIL 0 ≠ 台词好**，只代表没犯这十类硬错。真正的判断靠人工过单（见 §三）。

---

## 一、机检十项（`check_dialogue.py`）

| 码 | 判定 | 级别 | 实现口径 |
|---|---|---|---|
| **D1** | 说话人前缀被改动 | 🔴 FAIL | 逐行比对改写前后 `说话人+冒号` 前缀，必须完全一致 |
| **D2** | 台词行数变化（增删行） | 🔴 FAIL | 改写数量 ≠ 映射条数，或 index 不在台词行集合内 |
| **D3** | 改了非台词行 | 🔴 FAIL | index 指向 `action`/`scene`/`sfx` |
| **D4** | 剧情事实锚点丢失 | 🔴 FAIL | 原句中的数字/时间词/人名，改后必须全部存在 |
| **D5** | 书面虚词 | 🟡 WARN | 命中 A 类表：是否/因此/从而/鉴于/予以/加以/可否/颇为/甚为/以及/由于/进行/兹/并且 |
| **D6** | 长句无气口 | 🟡 WARN | ≥25 字且句内无 `，。！？…、；——` |
| **D7** | 水词 / 纯应答 | 🟡 WARN | 整句（去标点）∈ 水词表，且改后仍为水词 |
| **D8** | 情绪直白宣告 | 🟡 WARN | 命中 `我很/我好/我太/我特别/我真的很 + 情绪词` |
| **D9** | 译制片腔 | 🟡 WARN | 命中 `对…感到` / `这不在…之内` / `我需要你…` / `我为…感到` |
| **D10** | 与同角色台词完全重复 | 🟡 WARN | 同角色内，改后句子与他人/自己已有句子一字不差 |

### 事实锚点（D4）的白名单规则

只认**承载剧情的硬事实**（下例出自示例剧本）：

```
数字 + 单位：四块二 / 十七块八 / 四十一张 / 十二顿饭 / 五毛 / 三趟
时间词：今天 / 明天 / 昨天 / 上个月 / 十年前 / 那天下雨
人名/称谓：周小满 / 陈守义 / 马德胜 / 王婶 / 赵科长
地名：售票厅 / 站台 / 修理间 / 候车室 / 站长办公室
```

**不算事实**（不触发 D4）：
- 虚化量词：`一个`、`一下`、`一口`、`一点`、`一阵`、`一声`
- 语气词、连接词
- 方向词：`四周`、`四下`、`旁边`（同义替换不算丢）

> 这条白名单是踩过坑的：把"一个/一下"当事实锚点，会报一堆假警报。
>
> 另一个坑：`今天` 这种时间词最容易被顺手删掉。示例里把「今天上午十点之前」改成「上午十点那趟」，D4 立刻报 `事实丢失 ['今天']`——**不是误报，是真丢了**。时间锚点往往就是这场戏的时限压力，删了就松了。

## 二、改写前后必须守住的 6 条（对应 SKILL 硬约束）

```
D1 → 硬约束1（只改台词正文）
D2 → 硬约束2（不增删行）
D3 → 硬约束3（△/标题/音效零改动）
D4 → 硬约束4（剧情事实不增不减）
人工 → 硬约束5（不破人物身份）
人工 → 硬约束6（不改事件因果）
```

## 三、人工检查单（改完逐项打勾）

### 3.1 逐句四问

- [ ] 删掉这句，剧情会不会断？**不断且不爽感不掉 → 废句，回改**
- [ ] 这句能不能被对方听见？**听不见＝自言自语**
- [ ] 这句有没有接住上一句？**没有＝各说各话**
- [ ] 遮住角色名，认得出是谁？**认不出＝声纹崩了**

### 3.2 全场三查

- [ ] **删除测试过一遍**：随机抽 10 句删掉，看剧情是否有变化（无变化＝水词没清干净）
- [ ] **上下风没变**：原文谁压着谁，改完还是谁压着谁
- [ ] **信息没漏**：原文交代的事（谁做的、什么代价、什么时候），改完还能听出来

### 3.3 全篇两看

- [ ] **改动力度**：命中率在 **20–35%** 之间。>50% 说明改过头了（把 1 级改成 3 级）
- [ ] **句号比例**：是否降到 80% 以下（说明情绪层次出来了）。**但不要为了压指标批量加感叹号**——这是配音语调问题，不是文字病，真要动就单独出一版"标点语气稿"，别混在台词优化里
- [ ] **语气词分配**：语气词是**按角色**加的，不是全篇铺。老技工/军人/冷面角色一个不加

## 四、验收流程

```
① 机检 → FAIL 必须 0；WARN 逐条看，能解释就放过
② 人工过单（§三）
③ 回读验证：段落数不变、台词外零改动、zip 完整
④ 出对照表 + 诊断报告
⑤ 交付
```

### 回读验证（必做）

```bash
python3 -c "
import sys
sys.path.insert(0,'scripts')
from parse_dialogue import build
a = build('原剧本.docx')['paragraphs']
b = build('优化稿.docx')['paragraphs']
print('段落数 原/新:', len(a), len(b))
diff = [x['index'] for x,y in zip(a,b) if x['text']!=y['text']]
print('实际改动:', len(diff))
print('非台词行被改:', len([i for i in diff if a[i]['type'] not in ('dialogue','os')]))
print('台词行数 原/新:',
      sum(1 for p in a if p['type'] in ('dialogue','os')),
      sum(1 for p in b if p['type'] in ('dialogue','os')))
"
```

**四项必须全对**：段落数不变 / 改动数 = 映射数 / 非台词行改动 0 / 台词行数不变。

> `apply_dialogue.py` 落盘后会自动跑这四项并打印，示例输出见 README。

## 五、常见翻车与处理

| 翻车 | 症状 | 处理 |
|---|---|---|
| 把所有短句都加长 | 全篇从"电报体"变成"文艺腔"，文笔从 2 级掉到 3 级 | 回退，只补 4 级（流水账）的句子 |
| 全员加语气词 | 陈守义也"吧""啊"起来，人设崩 | 按声纹台账分角色加，陈守义一个不加 |
| 把 os 的现代词改掉 | 穿越设定的信息差消失 | os 里的现代词是合法设定，禁止改 |
| 感叹号批量替换 | 全篇感叹，等于没有重音 | 一集 3–5 处为限 |
| 水词删成空句 | 行数变了，下游分镜对不上 | 删完必须补回等量信息，不能留空 |
| 把说明式交代全删 | 观众看不懂（信息缺口太大） | 说明式交代要**转**（改成追责/争夺），不是删 |
| 事实锚点被"顺手"删掉 | 时限压力、金额、人名丢失，后面剧情对不上 | 把 D4 的 FAIL 当成真错，逐条补回 |
