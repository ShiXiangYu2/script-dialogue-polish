# 01 · 诊断清单（九类病灶）

> **用途**：改之前先体检。不诊断就动手，等于把好句子改坏。
> **顺序**：P0 必改 → P1 该改 → P2 可改 → P3 不动。**P3 通常占多数，不要为了产出而制造改动。**
>
> 本文所有例句出自虚构示例剧本《末班车》（1995 年，县城长途汽车站），见 `examples/demo_episode.docx`。人物、情节、数字均属虚构。

---

## P0 · 必改（这四类直接违反「不要无效台词」）

### ① 水词 / 纯应答

**症状**：整句只有应答功能，去掉后对方照样能接下去。
清单：`嗯 / 哦 / 啊 / 好 / 好的 / 行 / 行了 / 知道了 / 明白了 / 懂了 / 是 / 对 / 没事 / 没什么 / 谢谢 / 对不起 / 走吧 / 快点 / 小心点 / 可以`

**判定**：整句（去标点后）**等于**清单词 → 命中。**注意**：`嗯。`单独成句且上下文是敷衍 / 迟疑 / 懒得接，是**有效**的（那是表演）；连续两句纯应答才是水。

**示例**：
```
周小满：我知道。              ← 单看是水，但下面阿亮接"你知道？"形成回声，有效
阿亮：票根我翻了，没找着。      ← 有效：表明他真去翻了，是周小满要利用的点
```
**改法**：见 02 · 删法。删不掉就**升级为有信息的应答**——把"我知道"换成"我知道，王婶今天在门口站了半个钟头"，信息就进来了。

---

### ② 复述已知 / 回声确认

**症状**：把对方刚说的话重复一遍，或复述观众刚看到的动作。
```
❌ 陈守义：刹车没动过。
  周小满：刹车没动过？
  陈守义：没动过。
```
**判定**：这句的**信息量 = 上一句的信息量**，且不带新立场 → 命中。

**为什么必改**：它对观众零信息，对关系零推动，纯占时长。短剧 90 秒一集，这种句子每出现一次就少 3 秒有效戏。

**改法**：把复述改成**质疑 / 施压 / 反证**——同样的词，加一个立场就活了：
```
✅ 周小满：没动过？谁签的字。
```
**例外**：真的"没听清 / 不敢信"时可用，但**只重复关键词，不重复整句**，且必须接一个反应动作。

---

### ③ 情绪直白宣告

**症状**：角色直接说出自己的情绪名词。
清单：`我很生气 / 我好难过 / 我很失望 / 我太开心了 / 我恨你 / 我害怕 / 我很担心 / 我心如刀绞`

**判定**：句中出现 `我很/我好/我太/我特别/我真的很 + 情绪名词` → 命中。

**改法**：见 02 · 转法（情绪 → 可见行为）。三选一：
- **借物说话**：`水开了。喝完这碗再走。`（= 我不留你）
- **答非所问**：问"你还恨我吗"→ 答"锅里的饭我热了三回"
- **掉尾**：`你要是敢动她——`（后半句不说）

---

### ④ 说明式交代（向观众解释背景）

**症状**：角色对**已经知道这件事的人**解释这件事，只为让观众听懂。
```
❌ 马德胜：你爹当年是为了护站上的公物才受的伤，站里才给你家留了这个岗。
```
**判定**：这句话的信息，**听话人本来就知道**（同站、同家、当事人）→ 命中。

**改法**（vendor · 七维维度5）：
- 双方已知的信息一律删
- 必须交代的，转成**争夺 / 质疑 / 交换**
```
✅ 周小满：十年前我爹那条腿，站里给的什么说法。
```
同一件事，从"介绍"变成"追责"，信息还在，戏有了。

---

## P1 · 该改

### ⑤ 书面虚词 / 译制片腔

**现代/年代剧 A 类禁用词**（台词里出现即标）：
```
是否  因此  从而  鉴于  予以  加以  可否  何以  颇为  甚为
以及  然而  由于  进行  兹  并且  亦  其（作代词时）
```
替换：`是否→是不是`｜`因此→所以/这么说`｜`以及→还有`｜`由于→因为`｜`进行+名词→直接动词`（"进行检查"→"查了一遍"）

**译制片腔**（中文剧本里最出戏的一类）：
```
❌ 我对你的行为感到非常失望。
❌ 这不在我的计划之内。
❌ 我需要你给我一个解释。
❌ 我为你的安全感到担忧。
```
**判定**：出现 `对…感到…` / `我需要你…` / `这不在…之内` / `我…你…` 的完整主谓宾书面句式 → 命中。

**改法**：`我对你的行为感到失望` → `行。`（转身）；`我需要你解释` → `说清楚。`

> 实例：`我需要你给我出一份证明，说明这辆车的刹车在今天上午十点之前是完好的` → `给我写个条。今天上午十点那趟，刹车是好的。`

---

### ⑥ 流水账（文笔 4 级）

**症状**：只有"谁做了什么"，读完脑子里没有画面。这是**最普遍**的病灶。
```
❌ 周小满：我去把票根收起来。
❌ 马德胜：这个事我们要研究一下。
```
**判定**：抽掉人物和事件后，**没有任何可感的细节**（动作方式 / 物件 / 数字 / 声音 / 停顿）→ 命中 4 级。

**改法**：补**一个**具体锚点，不要补三个（补多了变 3 级堆砌）：
```
✅ 周小满：票根我按日期码好了，压在玻璃底下。
✅ 马德胜：这事得开会。研究完再说。
```
数字、物件、动作结果——任选一个，画面就出来了。

---

### ⑦ 句式撞车

**症状**：不同角色、不同场次反复用同一个句型。这是"全员一个腔"最硬的证据。

**示例**：阿亮的 `那我呢。` 一集里出现 3 次；`凭什么。` 出现在 4 个不同角色口中。

**判定**：
```
python3 scripts/parse_dialogue.py 剧本.docx --duplicates
```
同句 ≥3 次、且**不是刻意回环**（刻意的回环必须相邻、且中间有反应）→ 命中。

**改法**：保留最有位置的那一次，其余换句型：
- `你怎么知道。` → `谁告诉你的。` / `这话哪来的。` / `你打听过。`
- `为什么。` → `为啥。` / `图什么。` / 直接不问了，用动作（抬头看他，不说话）

---

## P2 · 可改

### ⑧ 堆词（文笔 3 级）

**症状**：形容词 / 四字词 / 抽象词堆在一起，抽掉修饰什么都不剩。
```
❌ 阿亮os：这一摊子事跟乱麻似的，我心里说不清是什么滋味。
```
**判定**：句中形容词 + 成语 ≥3 个，或出现"岁月/宿命/情愫/灵魂/救赎"类抽象大词 → 命中。

**改法**：**删到只剩一个具体名词 + 一个动词**。
```
✅ 阿亮os：票根上的数，对不上。
```
注意：3 级要**删**，4 级要**补**，方向相反，别搞反。

---

### ⑨ 节奏单调

**三个可量化指标**（下面是示例剧本 47 句的实测值，样本小，**只作口径演示**，你的稿子以自己实测为准）：

| 指标 | 健康区间 | 示例剧本实测 | 说明 |
|---|---|---|---|
| 句尾语气词占比 | 25–40% | 14.9% | 偏低。市井/中年/妇女角色应更高 |
| 句末用句号占比 | ≤80% | 83.0% | 过高 → 全是平陈述，情绪不显 |
| 句长标准差 | ≥5 | 7.6 | 尚可，但长短对比不够 |
| 疑问句占比 | 15–30% | 10.6% | 偏低 → 缺逼问、缺对抗 |

**改法**（克制，不要全篇加感叹号）：
- 该急的地方给短句 + 句号断开（`回去。现在。`）
- 该软的地方加语气词（`你先回吧。`）
- 一整个对话回合里，**至少有一句长短反差**

**禁止**：把句号批量改感叹号。感叹号是重音，一集用 3-5 处就够，多了全平。

---

## P3 · 不动

以下情况**必须保留原文**，改了就是破坏：

| 情况 | 为什么不动 |
|---|---|
| 已经达 1 级（有画面感的短句） | 如 `陈守义：写不了。`——三个字抵一句长台词，改了必坏 |
| 刻意的极简 / 惜字如金 | 人物设定如此，不是缺陷 |
| 刻意的回声（相邻两句同词） | 那是节奏设计，如 `周小满：我知道。/ 阿亮：你知道？` |
| 官腔（人物设定就是官僚） | 标注`【本段官腔为人设·非缺陷】`，不改。如马德胜「年轻人，工作上有疏忽，谁都难免」 |
| 宣判 / 压迫 / 仪式段 | 本就该"不口语"，改了会泄气 |
| os 里带信息的关键句 | os 是稀有额度，只润不删 |

---

## 诊断产出格式

```markdown
## 诊断报告

**总台词**：45 句对白 + 2 句 os ｜ **角色** 6 个

| 病灶 | 命中 | 占比 | 优先级 |
|---|---|---|---|
| ① 水词/纯应答 | 3 | 6.4% | P0 |
| ② 复述已知 | 1 | 2.1% | P0 |
| ③ 情绪直白宣告 | 0 | 0% | P0 |
| ④ 说明式交代 | 0 | 0% | P0 |
| ⑤ 书面虚词/译制片腔 | 2 | 4.3% | P1 |
| ⑥ 流水账（4级） | 2 | — | P1 |
| ⑦ 句式撞车 | 0 组 | — | P1 |
| ⑧ 堆词（3级） | 1 | 2.1% | P2 |
| ⑨ 节奏单调 | 全局 | — | P2 |
| **P3 保留** | 多数 | — | 不动 |

**结论**：这份稿子 P0 命中 4 处，主要问题在 ⑨ 节奏（句号 83.0%、语气词 14.9%）。
不建议全篇重写——按 P0→P1→P2 精准打点。
```

**这份报告必须先给用户看**，让他知道"改哪些、不改哪些、为什么"。
